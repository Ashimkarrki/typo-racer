# Typo-Racer

Typo-Racer is a fast-paced, web-based multiplayer typing race game built with React and Firebase. Challenge your friends in real-time by creating or joining teams, and race against the clock to see who types the fastest.

## 🚀 Features

### 👥 Create & Join Teams  
- Players can create custom teams or join existing ones to compete together.
